AWS Cloud Essentials

A quick overview of key Amazon Web Services

Amazon EC2 (Elastic Compute Cloud)

Provides resizable, scalable virtual servers (instances) to run applications in the cloud with full administrative control.

Amazon S3 (Simple Storage Service)

Object storage built to retrieve any amount of data from anywhere. Ideal for backups, media hosting, and data lakes.

AWS Lambda

A serverless compute service that lets you run code in response to events without provisioning or managing servers.

Amazon RDS (Relational Database Service)

Simplifies setting up, operating, and scaling relational databases like PostgreSQL, MySQL, and MariaDB in the cloud.
